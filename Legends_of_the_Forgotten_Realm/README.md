# Legends of the Forgotten Realm

## Project Overview

**Legends of the Forgotten Realm** is a Python-based, command-line, turn-based RPG (Role-Playing Game).

The game takes place in the kingdom of Eldoria, where players choose a character class, explore different regions, fight enemies and powerful bosses, collect weapons and armour, use potions, and improve their characters through experience points and levelling.

The ultimate objective is to progress through the adventure and defeat the final boss, the **Ancient Demon King**.

## Features

### 1. Character Selection

Players can choose from four character classes:

- Warrior
- Mage
- Archer
- Assassin

Each character class has its own abilities and gameplay style.

### 2. Combat System

- Turn-based combat.
- Character skills and mana system.
- Critical hits.
- Defence mechanics.
- Enemy attacks.
- Boss battles.

### 3. Weapons and Equipment

- 21 weapons across 7 rarity levels.
- 12 armour sets.
- Character equipment management.
- Different equipment options to improve character abilities.

### 4. Inventory and Potions

- Inventory management.
- 15+ potions.
- Health and mana recovery.
- Equipment management.
- Random loot collection.

### 5. Enemies and Bosses

- 25+ different enemies.
- 10 powerful bosses.
- Different combat challenges.
- Final boss: Ancient Demon King.

### 6. Experience and Level System

- Earn experience points (XP).
- Level up your character.
- Improve character progression.
- Develop stronger combat abilities.

### 7. World Exploration

- Explore 10 different regions.
- Progress through the kingdom of Eldoria.
- Encounter enemies and bosses.
- Collect rewards and loot.

### 8. Save and Load System

- Save game progress using JSON.
- Load previously saved progress.
- Continue an existing adventure.

### 9. Game Completion

- Game-over screen.
- Victory screen.
- Final boss encounter.
- Adventure progression.

## Requirements

- Windows operating system.

- Command Prompt (CMD).

No additional package installation is required.

## How to Run the Project Using CMD

Follow these steps to execute the game on Windows.

### Step 1: Open Command Prompt

1. Press the Windows key.
2. Search for `cmd`.
3. Open Command Prompt.

### Step 2: Navigate to the Project Folder

Use the `cd` command to enter your project folder.

If your project is saved on your Desktop, type:

```cmd
cd /d "%USERPROFILE%\Desktop\Legends_of_the_Forgotten_Realm"
```

If your project is saved somewhere else, replace the path with your actual project folder location.

### Step 3: Check Python Installation

Enter:

```cmd
python --version
```

If that command does not work, try:

```cmd
py --version
```

You should see your installed Python version.

### Step 4: Check Project Files

Enter:

```cmd
dir
```

Make sure you can see the following files:

```text
main.py
game.py
data.py
player.py
systems.py
storage.py
```

### Step 5: Execute the Game

Type:

```cmd
python main.py
```

Alternatively, if your computer uses the Python launcher:

```cmd
py main.py
```

The game should now start in your Command Prompt window.

## How to Play

1. Run the game using `python main.py`.

7. Collect weapons, armour, potions, and loot.
8. Gain XP and level up your character.
